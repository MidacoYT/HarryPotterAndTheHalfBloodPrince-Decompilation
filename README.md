# Harry Potter and the Half-Blood Prince — Decompilation

An unofficial reverse-engineering and decompilation project for **Harry Potter and the Half-Blood Prince (2009)**, developed by EA Bright Light.

## Overview

The goal of this project is to analyze, document, and progressively reconstruct the original PC game's executable and internal systems.

The long-term objective is to produce a maintainable C++ codebase that can help with understanding the game, developing mods, and potentially improving compatibility with modern systems.

## Project Goals

- Reverse-engineer the original Windows executable.
- Identify and document functions, classes, and internal game systems.
- Reconstruct game logic in readable C++.
- Analyze the rendering, audio, input, and gameplay systems.
- Build a foundation for advanced modding tools.
- Track decompilation and reconstruction progress.

## Current Status

**Early development — Work in progress**

The repository is currently being initialized. Reverse-engineering research and code reconstruction will be added progressively.

## Tools and Technologies

- **IDA Pro / Ghidra** — Static analysis and decompilation.
- **C++** — Source code reconstruction.
- **Python** — Analysis automation and tooling.
- **AI-assisted analysis** — Function identification and documentation.
